- The mfd/ai-filemetadata integration supports `^1.6 <1.7.2`, now including 1.7.1 ([#96](https://github.com/netresearch/t3x-nr-llm-compat/issues/96)). On 1.7.1 and later the bridge takes the new `EventDispatcher` constructor argument into account, dispatches `ModifyRequestDataEvent` with the same request data as the original, and passes a listener's change of the system prompt on as nr-llm's prompt (sent in the user message, as for the extension's own prompt; the original's fixed user text is not sent). A detail level of `auto`, nr-llm's own default, counts as unchanged. Any other listener change (for example added tools, another model, a changed temperature, a token limit or an image detail level of `low` or `high`) makes the bridge refuse the request with an `UnmappableRequestChangeException` naming the changed keys (the bridge itself logs it at debug level only); the request is never sent to OpenAI instead. Temperature and token limits are refused because nr-llm's vision providers do not send a temperature ([netresearch/t3x-nr-llm#1474](https://github.com/netresearch/t3x-nr-llm/issues/1474)) and nr-llm reports no finish reason to detect a truncated answer ([netresearch/t3x-nr-llm#1473](https://github.com/netresearch/t3x-nr-llm/issues/1473)); the detail level is refused because only some nr-llm providers send it. From 1.7.1 on an empty answer raises an `UnexpectedValueException`, so no empty alt text is stored; up to 1.7.0, whose upload listener catches no exception, the bridge keeps returning an empty string, which ai_filemetadata stores with its generation date and does not retry. An empty (0-byte) image returns an empty string on every version, so the file is marked done. `nrllm:compat:status` names the registered `ModifyRequestDataEvent` listeners while the integration is active or available. A CI cell runs the unit and functional tests against 1.7.0. The range ends at 1.7.1 because the bridge rebuilds the request data itself and upstream changed that contract in a patch release; each new release is diffed before the range is widened.
