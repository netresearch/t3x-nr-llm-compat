- mfd/ai-filemetadata 1.7.1 and later with a `ModifyRequestDataEvent` listener: while the AI File Metadata integration is active, a listener that changes anything but the system prompt (for example adds a web-search tool) makes the bridge refuse every request, so no alt texts are generated and each refusal is logged as a warning. `nrllm:compat:status` names the registered listeners. Remove or adapt such a listener, or leave the integration disabled ([#96](https://github.com/netresearch/t3x-nr-llm-compat/issues/96)).
